# QA report: PBY Queue MVP

Branch `claude/tender-thompson-kvtnaw` (PR #4), reviewed on 2026-09-25 against `DECISIONS.md`,
`FEATURES.md`, `design/DESIGN.md`, `IMPLEMENTATION_NOTES.md` and `README.md`.

Scope: a clean `npm ci` and the full pipeline, every MVP row in FEATURES.md, a security review
(the app holds guests' phone numbers and is reachable from the internet), robustness, and a
phone UX walkthrough at 390x844 in light and dark themes. Where it was practical, each bug got a
failing test first, then a minimal fix.

**Summary:** 12 findings fixed (1 High, 6 Medium, 5 Low) and 6 left open (2 Medium, 4 Low),
plus 2 spec nits. The baseline pipeline passed before any change, and passes after all of them.

## Recommended fixes for open items

- **#13 Self-join limit behind shared IPs:** key the limit on (IP, event) and raise it (for
  example 60 per 10 min), or make it configurable (`SELF_JOIN_PER_IP`). The other defences stay:
  the honeypot, one active party per phone, and the 500-party cap. This needs the owner to
  confirm, because §2.10 fixes the number at 10.
- **#14 PIN lockout by strangers:** count the per-event lock per (event, IP) and add a much
  higher global threshold, or require the private event id (not the public join code) for PIN
  login, with helpers joining from a host-shared link.
- **#15 Twilio self-join texts:** add a per-event hourly cap on Twilio join texts from
  self-join (for example 60), or send the join text only after the status page has been opened
  once.
- **#16:** put `GET /api/join/:code` behind the same per-IP miss limiter as unknown status
  tokens.
- **#17:** send host devices party-level diffs, or leave rendered SMS bodies out of the snapshot
  and render them on the device (the template code is already shared).
- **#18:** store `last_host_action_at`, updated only by authenticated host routes, and use it
  for auto-close.
- **Deployment note:** with `TRUST_PROXY=1`, anything that reaches port 3000 directly can still
  forge `X-Forwarded-For`. Behind Cloudflare Tunnel, do not forward port 3000 on the router. If
  cloudflared runs on the same Docker host, bind the port to the LAN or loopback (for example
  `127.0.0.1:3000:3000`). The README now warns against publishing the port.

## Security review notes

| Topic                     | Result                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PIN hashing               | scrypt (N=16384, r=8, p=1, 16-byte random salt), compared with `timingSafeEqual`. 6–12 letters or digits. Never stored or logged in plain text. OK.                                                                                                                                                                                                                                            |
| Session cookie            | 256-bit random token, stored only as SHA-256. `HttpOnly`, `SameSite=Lax`, `Secure` on HTTPS (`COOKIE_SECURE=auto`, verified behind a tunnel), 12 h, one cookie per event, at most 5 per event, all cleared on close. OK.                                                                                                                                                                       |
| PIN brute force           | 5 failures per IP per minute blocks that IP for 60 s; 20 per event per hour locks the event for 15 min. Both were bypassable through the forged-IP issue (#1, fixed). See #14 for the lockout abuse.                                                                                                                                                                                           |
| `ADMIN_PASSWORD`          | **Needed:** it is the only thing stopping strangers from creating events, and with Twilio configured, from texting any number at the owner's cost. It is used only by `POST /api/events`, compared in constant time and limited per IP. It is dangerous only when weak, left as the placeholder, or open to unlimited guessing (#1 and #4, both fixed). It gives no access to existing events. |
| Authorization             | Every host route requires a valid session for the `:id` in the path. Party, text and undo lookups are scoped to that event (they return 404 for another event's ids). A guest token can only read its own status, tap **I'm here**, and open a read-only WebSocket that has no message handler. Closed events refuse all changes.                                                              |
| Guest payloads            | No phone numbers, tokens of other parties, notes or members. Names follow G2 everywhere, including the guest's own (#3). Covered by API and e2e assertions.                                                                                                                                                                                                                                    |
| Twilio webhook            | `X-Twilio-Signature` is an HMAC-SHA1 over `PUBLIC_URL` (or the forwarded scheme and host) plus the path and sorted parameters, compared in constant time. Behind a tunnel with no `PUBLIC_URL`, correct signatures pass and http or foreign-host signatures fail (test added). STOP and START are handled with an empty TwiML reply (no confirmation text of our own).                         |
| SQL injection             | Every query is a prepared statement with bound parameters; no SQL is built from strings from requests.                                                                                                                                                                                                                                                                                         |
| XSS                       | React escapes all text. There is no `dangerouslySetInnerHTML`. Names such as `<img onerror>` are stored and shown as text. `href`s are built from server-generated tokens and codes only.                                                                                                                                                                                                      |
| `sms:` URIs               | The recipient is always a server-normalized E.164 number (`+` and digits only), and the body goes through `encodeURIComponent`, so nothing can be injected.                                                                                                                                                                                                                                    |
| CSV / XLSX / vCard        | Parsed on the device. SheetJS 0.20.3 comes from the vendor tarball (the npm copy is stale). Size, row and column caps were added (#11). The vCard parser is linear, with no regex backtracking on values. The server re-validates every row (#10) and limits request bodies to 2 MB.                                                                                                           |
| Tokens                    | Status links: 12 base62 characters with rejection sampling (about 71 bits). Ids: 14 base62 characters. Session tokens: 32 random bytes. Join codes: 6 characters from an unambiguous 32-character alphabet (30 bits, public by design).                                                                                                                                                        |
| Secrets in the repository | None. The only hard-coded password is the e2e test's `e2e-admin`. `.env`, `*.db` and `data/` are git- and docker-ignored.                                                                                                                                                                                                                                                                      |
| Docker                    | Multi-stage build on `node:22-bookworm-slim`, runs as the unprivileged `node` user (uid 1000), `/data` is owned by `node`, no build tools in the final image, has a health check.                                                                                                                                                                                                              |
| Logs                      | Status tokens are redacted from request URLs, phone numbers are masked (`+1******1234`), and SMS bodies are never logged or stored.                                                                                                                                                                                                                                                            |

### Defaults and rules checked

- **Defaults:** Up next N 2 (range 0–5, where 0 turns it off); estimate 3 min per party before
  any data; mean of the last 5 samples, ignoring those under 15 s or over 20 min, clamped to
  1–15 min; rounded up, and shown as `90+ min` above 90; party size 1–20 (default 1); 500 active
  parties; 500 rows per import; 5 helper devices; 12 h sessions; 7-day retention.
- **Templates (worst case: 20-character event name, 12-character first name, 3-digit position,
  `90+` wait, and a 48-character link, longer than the spec's 45):**

  | Template  | Length | With STOP footer              |
  | --------- | -----: | ----------------------------- |
  | join      |    129 | 152                           |
  | up_next   |    143 | 152 (after dropping the name) |
  | your_turn |     82 | 105                           |
  | skipped   |    149 | 158 (after dropping the name) |

  All are ≤160 and GSM-7. Accented names are transliterated to ASCII and emoji are dropped.
  `{link}` is never truncated.

- **Skip / no-show:** skip, skip, then no-show on the 3rd; a skipped party goes back in at
  position 4 and a no-show at the end (unit tests in `shared/test/queue.test.ts`).
- **Phones:** 10 digits, or 11 starting with 1, become E.164; US area codes and exchanges
  starting with 0 or 1 are rejected; `+` with 8–15 digits is treated as international
  (tap-to-send only, and now never `+0…`); garbage is kept flagged, with no texts.

## UX walkthrough (390x844, light and dark)

`e2e/qa-ux.spec.ts` walks the host dashboard, the texts tray, the party sheet, the Add sheet,
the party editor, the missed list, Settings, Share, New event, the events list, and the guest
